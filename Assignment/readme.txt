Part 1
Files Included:

Booking Function

- booking.html      - Passenger booking form page
- booking.js        - Client - side input validation and sends data from the server
- booking.css       - Stylesheet
- booking.php.      - Handles server - side logic which process booking request

Admin Function

- admin.html        - Admin page which manages booking requests
- admin.js          - Client - side search validation and sends data to the server
- admin.css         - Stylesheet
- admin.php         - Handles server - side logic which retrieves booking requests through booking_ref

How to run the system:

- Extract Part1_vpk8065.zip
- Upload all project files to the aut web server using FireZilla or WinSPC
- Ensure all the files from Part1_vpk8065.zip is included 
- Drag the file to htdocs directory
- Open any browser (chrome, edge, etc...)

BOOKING PAGE
- paste this url "http://webdev.aut.ac.nz/~<AUT_Username>/assign/booking.html"
- If successful, fill up the form try to submit a booking request
- If successful, booking confirmation message appears.

ADMIN PAGE
- paste this url "http://webdev.aut.ac.nz/~<AUT_Username>/assign/admin.html"
- If successful, search the booking request by putting the booking reference of the request
- If successful, it shows the booking requests information.
- To assign, click assign button then confirmation message appears.

DATABASE SETUP

- To simulate a database use the MySQL commands from my mysqlcommand.txt
- Run these commands in phpMyAdmin using AUT webdev credentials.
- Make sure to connect to AUT server when creating database.
- If wanted to connect remotely just open "https://distance.aut.ac.nz/login/".
